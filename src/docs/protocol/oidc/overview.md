# 协议概述
## OIDC（OpenID Connect）
OpenID Connect（简称OIDC）是一个基于OAuth 2.0协议的身份认证层协议，它允许客户端应用验证用户的身份并获取基本的用户信息。

## JSON Web Token 结构是什么？
+---------------------------------+
|           OIDC 应用层           |
| (身份认证、用户信息、会话管理)   |
+---------------------------------+
|           OAuth 2.0 层          |
| (授权、令牌、端点、客户端类型)   |
+---------------------------------+
|           HTTP/HTTPS 层         |
| (传输安全、RESTful 通信)        |
+---------------------------------+


### 令牌结构
ID Token (JWT 格式)：
```
{
  "iss": "https://server.example.com",  // 签发者
  "sub": "248289761001",               // 用户唯一标识
  "aud": "s6BhdRkqt3",                 // 目标受众(客户端ID)
  "exp": 1311281970,                   // 过期时间
  "iat": 1311280970,                   // 签发时间
  "auth_time": 1311280960,             // 认证时间
  "nonce": "n-0S6_WzA2Mj",             // 防重放攻击值
  "acr": "urn:mace:incommon:iap:silver", // 认证上下文类
  "amr": ["pwd", "mfa"],               // 认证方法参考
  "azp": "s6BhdRkqt3",                 // 授权方(客户端ID)
  // 可选的标准声明
  "name": "Jane Doe",
  "email": "janedoe@example.com"
}
```

### 协议协议端点
|端点类型	|标准路径	|功能描述|
|:-|:-|:-|

|授权端点	|/authorize	|用户认证和授权交互 |
|令牌端点	|/token	|获取令牌 |
|用户信息端点	|/userinfo	|获取用户详细信息 |
|发现配置端点	|/.well-known/openid-configuration	|服务发现元数据 |
|JWK 端点	|/jwks	|提供验证签名的公钥集 |
|撤销端点	|/revoke	|令牌撤销 |
|会话管理端点	|/endsession	|终止会话 |
