# 协议概述
表单代填就是在浏览器端通过模拟登录页面表单提交，进行登录操作。表单代填实现单点登录，优点在于应用系统可以不做任何改造。

在应用系统不支持任何标准单点登录协议，也不可进行系统改造的情况下，可考虑使用表单代填的方式实现单点登录。



利用这种实现单点登录的方式，`EMIS` 需要把用户名和密码提交给后台的应用系统来完成认证工作，因此需要在 `EMIS` 中，维护一套 `EMIS` 用户和后台应用系统中用户名/密码的对应关系表，如下：

`EMIS` 用户：formusername

|应用系统名	|用户名	|密码|
|:-|:-|:-|
|应用系统A	|formusername	|****|
|应用系统B	|formusername_	|****|
|应用系统C	|formusername	|****|
