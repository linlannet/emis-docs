# 行为审计
审计日志详细地记录了用户在平台上进行的关键操作；通过管理员的行为记录，你可以得到所有管理员用户通过EMIS 多身份集成系统的行为；通过对普通用户的行为记录，可以清晰得还原出用户在门户中心中的行为，以支持政府、事业单位、企业等组织机构的合规管理，同时可用作事件发生后的回溯和定责。

## 门户用户行为
主要记录门户用户在EMIS 多身份集成系统的行为记录。
1. 在左侧导航栏，选择行为审计，进入行为审计列表。
![门户用户行为](/assets/img/c-1.6-audit-portal-list.png "门户用户行为")

2. 展开控制台管理员记录，查看事件详情，详情包含字段包含操作者、操作者类型、事件时间、事件类型、事件状态、客户端 IP 等相关字段；

## 控制台管理员行为
主要记录管理员用户在EMIS 多身份集成系统的行为记录。
1. 在左侧导航栏，选择行为审计，进入行为审计列表。
![控制台管理员行为](/assets/img/c-1.6-audit-console-list.png "控制台管理员行为")

2. 展开控制台管理员记录，查看事件详情，详情包含字段包含操作者、操作者类型、事件时间、事件类型、事件状态、客户端 IP 等相关字段；

## 行为审计查询
在控制台管理员行为中，可通过事件类型、事件时间区间进行查询检索。
![控制台管理员行为查询](/assets/img/c-1.6-audit-console-search.png "控制台管理员行为查询")
