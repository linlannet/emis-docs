# 身份提供商
本节将介绍如何在 EMIS 多身份集成系统，新建认证源、启用/禁用认证源。

EMIS 多身份集成管理系统支持配置多种外部身份提供商。管理员可以根据需要，添加并启用不同的认证方式。启用认证源并完成配置后，平台会在公司用户登录时使用具体的认证源去认证用户身份，并通过外部 ID 与平台的用户进行关联。

## 身份提供商列表
管理员登录 EMIS 多身份集成系统，在左侧导航栏，选择认证管理 > 身份提供商，进入系统身份提供商列表，系统支持社交认证源和企业认证源。

![社交认证源](/src/assets/img/c-1.4-provider-list-social.png "社交认证源")

```配置社交认证源身份提供商
配置相对应的身份提供商，请根据以下进行配置：

- 微信
- QQ
- 支付宝
- GITEE
- GITHUB

```

![企业认证源](/src/assets/img/c-1.4-provider-list-ent.png "企业认证源")

```配置企业认证源身份提供商
配置相对应的身份提供商，请根据以下进行配置：

- 钉钉
- 飞书
- 企业微信
```

注：由于两种认证源操作相同，本文介绍的操作也可以用在社交认证源页面。
## 添加身份提供商
1. 单击添加认证源按钮。

![社交认证源](/src/assets/img/c-1.4-provider-social-add.png "社交认证源")

2. 完善身份提供商信息，点击确认完成添加。


| 参数 | 说明 |
|:-|:-|
| 认证提供商 | 身份验证提供商信息 |
| 认证源名称	| 管理员可以自定义认证源名称 |
| AppId	| 在您选择的身份提供商平台中申请获取的 AppId |
| AppSecret	| 在您选择的身份提供商平台中申请获取的 AppSecret |
| 是否显示	| 是否在 EMIS 多身份集成管理系统登录页显示认证源 |
| 备注	| 认证源备注信息 |

3. 添加完成后，系统会自动生成一个地址，请将此地址配置为对应平台的回调地址。

## 修改身份提供商
1、找到需要配置的身份提供商，单击修改。


2、按照内容输入修改基本信息


## 删除身份提供商
1. 找到要删除的身份提供商，点击删除。

2. 进行删除确认，完成身份提供商删除。


## 启用/禁用身份提供商
已添加的身份提供商，管理员可以启用和禁用。该提供商在禁用状态时，EMIS 用户不可以通过该认证源登录。

1. 在身份提供商页面，定位到要操作的身份提供商，单击启用。

2. 如果禁止用户使用该登录方式登录，定位到要操作的身份提供商，单击禁用。
